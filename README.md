# 📐 Math Problem Solver / მათემატიკური ამოცანების ამოხსნა

An interactive, responsive web application for solving circle geometry, visualising fractions, and calculating work-rate math problems with multi-language support.

ინტერაქტიული ვებ-აპლიკაცია წრის გეომეტრიული პარამეტრების, წილადების ვიზუალიზაციისა და ერთობლივი სამუშაოს/მილით ავსების ამოცანების ამოსახსნელად.

---

## ✨ Features / ფუნქციები

### 🇬🇧 English
- **🔵 Circle Properties Engine:** Calculates radius, diameter, circumference, area, arc length, and sector area with visual SVG rendering.
- **🔢 Fraction Solver & Visualizer:** Supports fraction arithmetic with step-by-step solutions and dynamic fraction bar visualizations.
- **⚡ Work-Rate Solver:** Solves combined worker and pipe filling/emptying word problems.
- **🌐 Multi-Language Support:** Includes 12 supported languages.

### 🇬🇪 ქართული
- **🔵 წრის გეომეტრია:** ითვლის რადიუსს, დიამეტრს, პერიმეტრს (სიგრძეს), ფართობს, რკალის სიგრძესა და სექტორის ფართობს SVG ვიზუალიზაციით.
- **🔢 წილადების კალკულატორი:** ახდენს წილადების მიმატებას, გამოკლებას, გამრავლებასა და გაყოფას ეტაპობრივი ინსტრუქციითა და ვიზუალური ბარებით.
- **⚡ ერთობლივი სამუშაო:** ხსნის მუშების ერთობლივი შრომისა და მილებით აუზის ავსება-დაცლის ამოცანებს.
- **🌐 მრავალენოვანი მხარდაჭერა:** 12 ენის მხარდაჭერა.
